# 图形字体

Noto Sans SC，SIL Open Font License 1.1，见 `OFL.txt`。
来源：https://github.com/google/fonts/tree/main/ofl/notosanssc

`setup_paper_fonts.py` 校验官方变量字体的 SHA256，并生成字重 400 的 TrueType 字体。源码摘要：`a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`。

`NotoSansSC-Regular.ttf` 不提交 Git，随完整交付包提供；PDF 嵌入字体，SVG 使用字形路径。
