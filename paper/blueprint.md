# 论文论证蓝图（2026-09-24 重构版）

## 结构选择

采用“统一底座 → Q1 → Q2 → Q3 → Q4 → 统一敏感性 → 验证评价 → 结论”。Q4 直接固定 Q3 的正式安排，先讲它可避免在四问中间插入总结性分析。第 3 节一次定义物理规则；第 4–7 节只定义新增决策及约束，避免各写一套公式。

参考优秀论文的结构能力：每问先提出尚未解决的矛盾，再论证模型/算法选择，最后用验证和小结接续下一问。不采用参考论文的具体内容、模型、算法、数据、表述和结论。

## 详细目录与逐节论证任务

摘要（正文稳定后写）：每问给出模型、真实结果及精确性范围，最后交代最紧证据和边界。

| 标题（一级/二级/三级） | 这一节要证明什么 |
|---|---|
| 1 问题重述与总体分析 | 本题是一条从能力到执行、通信再到资源独立性的递进链。 |
| 1.1 山区投送的核心矛盾 | 距离可达、装得下和实际可执行是不同要求。 |
| 1.2 四问的递进关系与继承边界 | 继承模型不等于照搬上一问分组，Q3→Q4 才直接固定计划。 |
| 1.3 总体技术路线 | 同一个物理底座支撑四层决策，结果由统一证据链回放。 |
| 2 模型假设、数据与符号 | 官方规则、补充假设、算法选择需要可区分且可追溯。 |
| 2.1 题设规则与适用假设 | 无风场、确定性输入和地形近似限制了结论外推。 |
| 2.2 数据校验与结果溯源 | 编号、单位和文件版本一致是后续计算的前提。 |
| 2.3 统一符号与时间口径 | 累计作业与并行完工不能混为一谈。 |
| 3 地形—载荷—能量统一计算模型 | 所有任务从相同航段对象获得时间、能量与状态。 |
| 3.1 DEM 航高与飞行阶段 | 最高沿途地形决定巡航高度，多点投送须逐次重新爬升。 |
| 3.2 动态载荷与等效航程 | 卸货改变后续能耗，返程为空载但仍耗能。 |
| 3.3 分阶段能量与返航储备 | 质量、体积和电量三类可行性缺一不可。 |
| 3.4 无人机与能源资源的独立占用 | 飞机返航与电池完成充电是不同的释放时刻。 |
| 4 Q1：最大安全载荷与精确组批 | 连续能力边界还须转换为不可拆货箱的可执行批次。 |
| 4.1 为什么额定载荷不足以判断安全 | 地形爬升和空载返程共同挤占载货预算。 |
| 4.1.1 服务区—机型安全载荷边界 | 每个组合的安全载荷由额定上限和往返能量共同限制。 |
| 4.1.2 单调性与二分依据 | 可行载荷集合是区间，提高储备不可能扩大它。 |
| 4.2 不可拆货箱的集合划分模型 | 按总质量平均分配不能保证质量、体积和能源同时可行。 |
| 4.3 锚定子集动态规划与精确性 | 子集覆盖和锚定递推不遗漏可行划分，精确性有明确范围。 |
| 4.4 组批结果、约束余量与小结 | Q1 给出能力基准，但没有给出实体资源和时限安排。 |
| 5 Q2：从运输能力到可执行调度 | 同时满足资源和时限需要重新选择分组与出发次序。 |
| 5.1 硬截止、软延误与资源冲突 | 完成交接才是交付，电池充电占用不能漏计。 |
| 5.2 确定性构造与有限候选搜索 | 算法是受限搜索、可行合并和资源重排，不是全局求解。 |
| 5.2.1 紧迫任务优先构造 | 先保障硬时限是形成初始可行计划的依据。 |
| 5.2.2 合并、重新调度与候选保存 | 少一架次可能改变多项资源释放时刻，必须重排全计划。 |
| 5.3 选点依据与运输结果 | 选定架次数是及时性与能耗的显式折中。 |
| 5.4 验证与向通信层的传递 | 运输资源可执行仍不保证山区链路可用。 |
| 6 Q3：通信保障下的运输—中继联合时序 | 给定空间/分组方案后，通信需求转化为窗口和时序约束。 |
| 6.1 离散计划与连续变量的边界 | 固定货箱、路线、资源顺序、中继位置/高度，LP 只调时序。 |
| 6.2 双向预算、地形遮挡与单跳判定 | 接入、回传和服务窗口须同时可行，沿全过程检查。 |
| 6.2.1 双向链路预算与 DEM 遮挡 | 单向发得出或几何距离近均不足以证明链路可用。 |
| 6.2.2 全阶段直连与指定中继保障 | 不能把不同中继的瞬时可用链路拼成实现中不存在的方案。 |
| 6.3 服务窗口与中继能量 | 中继越早建链、越晚结束，资源和能量代价越大。 |
| 6.4 固定方案下的词典序线性规划 | 固定航段后资源先后、窗口、截止与能量约束均为线性。 |
| 6.5 联合结果、采样证据与小结 | 方案在离散检查中可行但余量小，Q4 将固定其安排。 |
| 7 Q4：独立任务分区与资源配置 | 取消跨组共享会改变峰值资源配置而非运输需求。 |
| 7.1 从 Q3 继承任务与不可拆连通分量 | 同架次服务区必须归同组，组间中继复制规则必须明确。 |
| 7.2 区间峰值资源需求与精确枚举 | 对固定任务的区间分配，峰值并发等于所需最少同类资源。 |
| 7.3 配置缺口、方案比较与小结 | 两种分组的缺口是共享被限制的条件性代价。 |
| 8 敏感性与固定方案压力边界 | 可行、重新优化后的适应性、固定计划余量是三个层次。 |
| 8.1 储备变化与离散组批跳变 | 连续能力收缩可触发不可拆货箱重新分批。 |
| 8.2 固定运输计划的能耗容忍度 | 小幅统一能量上浮即可触及储备，不能称强鲁棒。 |
| 8.3 通信余量与可解释范围 | 额外损耗的采样容忍度不能外推成连续通信保证。 |
| 9 模型验证、评价与适用边界 | 用输入、重算、反例和约束余量支撑有限结论。 |
| 9.1 从数据版本到逐箱逐资源回放 | 独立读取结果并重算，验证的不只是表内自洽。 |
| 9.2 加密通信回放与最紧约束 | 1 s/0.5 s 通过及余量下降界定证据强度。 |
| 9.3 四类结论的精确性范围 | DP 精确、启发式候选、条件 LP、固定计划枚举严格区分。 |
| 9.4 模型优势、局限与改进顺序 | 优先补连续通信和紧能量余量，不能用软件 PASS 代替实飞。 |
| 10 结论（最后写） | 回收统一主线与真实产出，不添加新结果或扩大最优性。 |
| 附录：完整结果、复现与辅助使用记录 | 支持复核而不挤占正文论证。 |

## 图表论证契约

九张图各保留一个主要任务：总路线（四问继承）；地形/能量（距离不足以定能力）；安全载荷（额定/能量双边界）；组批（不可拆货箱）；Q2 权衡与甘特（选点和执行）；Q3 轨迹/余量（全过程通信）；Q4 库存/分组（独立性代价）；敏感性（连续参数/离散跳变）；验证（最紧约束/加密采样）。图形文件 ID 保持稳定，论文显示编号按新的引用顺序自动生成，契约章节同步更新。

新增的 Q2 相邻候选表来自原有 CSV，不新增求解或实验；关键结果均使用生成宏。图形阴影表示服务区范围，不代表置信区间。

## 事实与继承约束

- Q1 的单点载荷界不能直接筛掉一切多点路线；Q2/Q3 必须按实际访问顺序重新算能量。
- Q2 并未把 Q1 最优批次原样放入调度。Q3 也未在本轮自动搜索中继坐标或从当前 Q2 输出自动生成离散方案。
- Q3 使用指定的保障中继及当前组件单次使用结构；最优性仅针对这个固定离散方案和采样约束的时序 LP。
- Q4 直接固定 Q3 输出，但允许组内同类资源重新编号，并按组复制跨组保障的完整中继任务。
- 不新增风场、随机统计试验、实飞、全局下界、连续通信证明。
