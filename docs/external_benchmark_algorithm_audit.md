## 为什么原来慢、这次怎样改

上一版偏向20架次Q2和19架次Q3的低架次切片。现在先保证硬约束和零加权延误，再以完工、能耗、架次排序，在25运输/4中继上限内允许拆分。Q2采用60 s时间索引、能耗定价的有限架次列生成，用区间图着色恢复实体编号，保留充电完整占用；整数阶段筛选低约化成本列，再以连续时序与邻域精修。

Q3继承列生成，同时拓展按实体顺序生成中继窗口。新增CP-SAT联合资源邻域，一次选择机型、资源时序和中继匹配；整数秒向外取整，输出经原物理LP重新求时序。悬停候选从原225/300 m扩展为30–300 m多个高度并细化水平位置。两架物理中继执行三个架次，每次换点计入返航O01、周转、出航和建链。粗空间筛选只用于提案，完整1/0.5 s联合检查决定接受。

正式Q3优化链为：重算热启动6004.239947 s → 联合资源邻域5954.768034 s → 局部搜索5936.679443 s → 高度/位置细化5931.734694 s。热启动仅保存离散决策，不注入历史时刻、能耗或SOC；来源与限时搜索差异在config/completion_seed_provenance.json披露。

与原先WJ文字方案相同的方向是：航迹与地形显式计算、区间资源模型、列生成、空间覆盖和固定任务下分区穷举。差异在于WJ宣称的5340 s全局完成下界和1.47%间隙没有可复核附件；本仓库只报告有限目录LP、受限整数主问题及固定邻域下界，各自限定条件，不能互换。最新截图没有方法描述，不能把WJ的证明主张直接归给它。
