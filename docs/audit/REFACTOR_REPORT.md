## 第二轮独立复审记录

6. 再次比较独立运行与全流程，发现集合求和漂移，固定顺序后重跑。

## Remaining Risks

1. **连续通信证据有界。** 检查了 41,572 个离散状态并有保护时段，但仍不能排除采样点之间极短的通信中断。论文必须保留这一限制。
2. **离散方案搜索范围有限。** Q2 是启发式；Q3 的货箱/路线/中继位置/资源顺序固定，LP 仅优化相应时刻，且当前 LP 要求中继组件各用一次。库存或原始数据大改后可能无可行解，需要重新设计离散方案。
3. **几何与能耗解释。** 水平距离采用 WGS84 椭球，DEM 和阶段位置采用一致的经纬度直线；建链时段计悬停与通信功率。题目没有风场规则，正式流程不引入风修正。
4. **原始附件不可缺省。** 仓库不公开上传私人原始数据；新环境需用户放入官方附件，才可运行真实数据全流程。
5. **论文和 Excel。** 本轮未重写论文，也没有虚构不存在的官方工作簿导出器。历史文稿已标明旧数值，当前 CSV/JSON 可继续用于论文和后续模板导出工作。
6. **运行平台证据。** 本轮实际全量验证平台为 Linux/Python 3.12；Windows CI 配置用于进一步平台验证，不替代真实附件下的全量运行。
